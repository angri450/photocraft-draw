# 关于明确遮挡关系的意见

## 关于画家的思路

一张画不是一层层「摆」出来的，是从最远的地方开始，一层层往上盖。离观众越近的越后画，后画的自然盖住先画的。所以遮挡关系的本质是：**给每个部件一个离观众的距离，然后按距离从大到小画。**

## 关于三个判断

第一，谁站在地上，谁浮在空中。地面上的东西被前面地上的东西挡，天上的东西只被更高的东西挡。

第二，谁在谁的近侧。骑手跨在马背上，两条腿分在马身两边：靠近观众这一侧的腿，离观众比马身近，所以它挡马身；另一侧的腿在马身后面，被马身挡。同一个人，两条腿的深度不一样，不能一起算。

第三，两个东西交叉时，判断谁的身体更靠近画面底边。越靠近底边，说明站得越靠前，深度越浅。

## 关于深度的表示示例

从远到近：

| 深度 | 部件 | 依据 |
|---|---|---|
| 0 | 天空 | 最远，什么都没有 |
| 1 | 远山 | 被空气冲淡，在地平线上 |
| 2 | 近山 | 压住远山，山脚接岩地 |
| 3 | 岩地 | 山坡，接住山脚 |
| 4 | 河流 | 在岩地前面，水往低处流 |
| 5 | 远侧腿 | 在马身另一侧 |
| 6 | 马身 | 挡住远侧腿 |
| 7 | 近侧腿 | 在马身近侧，挡住马身 |
| 8 | 骑手上身 | 在马背上，最高最前 |
| 9 | 前景石 | 压住画面底边，最近 |

绘制顺序按深度从大到小：天空 → 远山 → 近山 → 岩地 → 河流 → 远侧腿 → 马身 → 近侧腿 → 骑手上身 → 前景石。

交叉的地方不用额外处理，后画的自动盖住先画的。要改遮挡关系，只改深度值，不动形状。

## 关于同一层里多个部件的先后

遮挡关系有两层。一层是层与层之间，就是上面那套画家的顺序。另一层是同一层内的多个组件之间，`custom_shape` 按列表顺序压盖，后面的组件盖住前面的组件。

这一层能拿来镂空。兽头画成一条闭合轮廓之后，再叠一个底色的嘴形，底色形状压在兽头上，嘴就张开了。牙、舌、衣襟上的高光，都能用同色或反色的形状叠出来。

压盖次序也有讲究。人物身上的亮边要放在主体之后，否则亮边会被主体盖住。同一层里放前景碎石，碎石就会盖住人物的脸。

## 关于实际代码的对照

`capsule_rider` 里的顺序是：马后腿 → 远侧腿 → 马身 → 颈头尾 → 近侧腿 → 骑手上身 → 马前腿。前腿放在最后，因为它抬起来在画面最靠前的位置。这个顺序和深度表一致，只是把「马」拆成了马身、马腿、马头三段，各段深度不同。

## 关于核对的方法

出 PSD 之后跑 `photocraft-draw occlusion out/a.psd`，它列出每一对遮挡关系和挡住的像素占比。占比明显不对，说明深度值写错了。
