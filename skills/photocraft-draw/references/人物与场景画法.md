# 人物与场景画法

## 人物画法

1. 头身比约 1:6.5；坐姿躯干约 2.2 个头高，肩宽约 1.6 个头宽。
2. 脸用三个面：额头到鼻梁一个、颊部一个、下颌阴影一个。眼睛只画上眼睑和一点暗部，不画圆眼珠；鼻子用一条侧影或三角形暗面；嘴只画一条短线。
3. 头发是包住头骨的一整片，边缘带两三个起伏；胡须是一片往下聚拢的形状，不画一根根线条。
4. 手分三到四个形状：手掌、拇指、并拢的四指、可选的前臂。手指不分开画，只画整体轮廓。
5. 袍子先铺大色面，再压两三处暗部褶，最后一条亮边；不要黑色描边。
6. 姿态至少区分：正面端坐、侧身转头、前倾撑桌、双手摊开、手指指向。

### 关节白模的摆位

`figure_rig` 的 `pose` 可以给内置名，也可以直接给 14 关节表，直接给表才能摆出想要的招式。关节表是「髋部为原点、向上为负 y、身高归一 1.0」的相对坐标，关节名固定：

```text
hip chest neck head
shoulder_l shoulder_r elbow_l elbow_r hand_l hand_r
knee_l knee_r foot_l foot_r
```

调用时给 `root`（髋部绝对位置）和 `height`（身高像素），关节表的每个数值乘以身高再加到 root 上。脚要站在某个高度时，用「脚底高度减 0.84 乘身高」反推 root。

摆多人时，关节球的直径比看上去大得多。关节球实画出来约 45 像素，两个人的横向间距留 70 像素以上才不会叠在一起。一排人像复制粘贴，多半是间距给小了。

前后两层拉开纵深，别让所有人站在同一条水平线上：后排的人矮两成左右，脚线高 50 像素左右，一眼就能看出远近。

### 演出朝向

figure_rig 的 face 参数定人物给观众看的这一面。四个值：front 正面朝观众，
left 侧身转向画面左侧，right 侧身转向画面右侧，back 背对观众。

白模本来分不出正反面。正面和背面都是一样宽的肩、一样圆的头，头上没有脸。
写上 face 以后，白模的头会点上五官。正面画两眼加鼻加嘴，侧身把五官往侧面挪
并加一个鼻尖，背面只画一道后脑线。这样一眼能看出脸朝哪边。

正面朝观众的人物，关节表照这五条摆。肩展开，肩宽占身高 0.2 以上；
头落在两肩中线上，偏出不超过身高的 0.07；脖子不拧，颈与躯干拧角 15 度以内；
躯干立着，偏离竖直 20 度以内；两肩一样高，高差不超过身高的 0.04。

项目规矩禁止背场。这一层怎么查，见 [关于确定演出朝向的思维链](关于确定演出朝向的思维链.md)。

## 配色规则

1. 避开纯黑和纯白。最暗用 `#38271c`，最亮用 `#b6aca5`。
2. 大面积铺低饱和土黄、赭石、灰绿；红色只出现在袍子和帷幔上，蓝色只出现在披风上。不要高饱和。
3. 主色按面积排序：

```text
#70655a  #877160  #38271c  #54483c  #4e3a29  #5f5042
#41372e  #9a8a79  #6a5440  #a3968c  #8f8379  #b6aca5
```

4. 现有 `fresco` 配色的角色映射：bg `#d9c7a3`，surface `#e6d7b8`，ink `#3a2a1e`，muted `#7a6a55`，deep `#6b2f24`，mid `#8a6a3a`，soft `#c9b48a`，line `#9c8a6e`，accent `#f6e6bd`。
5. 暮色场景用 `dusk` 配色：bg `#1b1524`，surface `#241c30`，ink `#f6ece0`，muted `#b8a9a0`，deep `#f2b880`，mid `#d97a5a`，soft `#6d3a5c`，line `#3a2f4a`，accent `#ffd88a`。适合天宫夜战、深宫、险恶场景。

## 场景构图规则

1. 画布参考 800×450，横向。地平线在 52% 左右，桌子压在前景 55% 到 85%。
2. 人物头部在画布高度的 26% 到 45% 之间。
3. 桌子以上露上半身，人物分组时按三人一组排开。

## 建筑与兽类轮廓

### 中式屋顶

只画两条斜面加一条平线，出来的是人字帐篷。要画成中式屋顶，得给六样东西：

1. 平正脊，正中一段水平的脊线，不要整条都是斜面。
2. 凹曲坡面，坡面靠近檐口处向上提，不是直线下来。
3. 檐口起翘，檐口两端各有一个向上的尖角。
4. 翼角，屋脊两端各翘一个钩。
5. 鸱吻，脊的两端各一个小兽头，贴着脊线画，不要让它飘在屋顶外面。
6. 檐下柱列，檐底排一列短柱，这样屋顶才像建筑。

平脊占全跨三成左右。脊太短、坡太缓，画出来还是帐篷。

### 兽类剪影

兽类用 `custom_shape` 画，不用 `figure_rig`。四步：

1. 身体一条闭合轮廓，头、颈、背、臀、腹都在这一条里，中途不另起一条。
2. 四条腿分前后两组，每条腿是大腿段加小腿段两段四边形，折角定在膝或肘。腿伸出的方向要分两组，前腿朝扑击方向伸，后腿朝反方向蹬。
3. 耳朵独立三角，尾巴独立一条曲线。尾巴甩起的弧度决定这只兽在干什么。
4. 嘴用底色形状叠上去，同层里后一个组件压住前一个。

腿画成放射状的多根细条，看起来就是蜘蛛。腿要粗，前组后组方向不一样，才看得出是兽。
